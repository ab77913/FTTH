Ollama Chat API

REST API for accessing all Ollama models on this server. Supports text, images, PDFs, DOCX, spreadsheets, and code files.

← Back to Chat Health Check List Models (JSON)

Base URL

/api/v1/
All endpoints return JSON. For streaming responses, the body is newline-delimited JSON (NDJSON). CORS is enabled on all /api/v1/ routes.

Health & Discovery

GET/api/v1/health
Check server status and Ollama connectivity.
curl /api/v1/health
{"status":"ok","ollama":"reachable","models":13}
GET/api/v1/models
List all available Ollama models with details.
curl /api/v1/models

Chat

POST/api/v1/chatJSON or multipart
Send a message and get a response. Supports text, file attachments, and conversation history.

Request fields

FieldTypeRequiredDescription
modelstring✓Model name, e.g. llama3:latest
messagestring✓*User text message (* required if no file)
filefile–Any file: image, PDF, DOCX, code, CSV…
conversation_idint–Continue an existing conversation (history auto-loaded)
streambool–Default false. Set true for NDJSON stream.

Text chat (JSON)

curl -X POST /api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"model":"llama3:latest","message":"Explain quantum computing in 3 sentences."}'

Image analysis (multipart)

curl -X POST /api/v1/chat \
  -F "model=qwen2.5vl:latest" \
  -F "message=What objects are in this image? Describe in detail." \
  -F "file=@photo.jpg"

PDF / document analysis

curl -X POST /api/v1/chat \
  -F "model=qwen2.5:14b" \
  -F "message=Summarize the key points of this document." \
  -F "file=@report.pdf"

Code review

curl -X POST /api/v1/chat \
  -F "model=deepseek-coder:33b" \
  -F "message=Review this code for bugs and suggest improvements." \
  -F "file=@main.py"

Continue a conversation

curl -X POST /api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"model":"llama3:latest","message":"What did I just ask you?","conversation_id":42}'

Conversations

GET/api/v1/conversations
List all conversations (newest first).
curl /api/v1/conversations
[{"id":1,"title":"Explain Python","model":"llama3:latest","updated_at":"2026-06-18 12:00:00","last_message":"Python is..."}]
GET/api/v1/conversations/{id}
Get full conversation including all messages and attachment metadata.
curl /api/v1/conversations/42
{"conversation":{...},"messages":[{"id":1,"role":"user","content":"...","attachment_name":"photo.jpg","attachment_type":"image","attachment_path":"abc123.jpg"}]}
POST/api/v1/conversations
Create a new empty conversation.
curl -X POST /api/v1/conversations \
  -H "Content-Type: application/json" \
  -d '{"model":"llama3:latest","title":"My new chat"}'
PATCH/api/v1/conversations/{id}
Rename a conversation or change its model.
curl -X PATCH /api/v1/conversations/42 \
  -H "Content-Type: application/json" \
  -d '{"title":"Renamed","model":"deepseek-coder:33b"}'
DELETE/api/v1/conversations/{id}
Permanently delete a conversation and all its messages.
curl -X DELETE /api/v1/conversations/42

Python Example

import requests

BASE = "/api/v1"

# Simple text chat
r = requests.post(f"{BASE}/chat", json={
    "model": "llama3:latest",
    "message": "Write a haiku about AI"
})
print(r.json()["response"])

# Image analysis
with open("photo.jpg", "rb") as f:
    r = requests.post(f"{BASE}/chat", files={"file": f}, data={
        "model": "qwen2.5vl:latest",
        "message": "Describe what you see"
    })
print(r.json()["response"])

# Multi-turn conversation
conv = None
for user_msg in ["Hello", "What did I just say?"]:
    r = requests.post(f"{BASE}/chat", json={
        "model": "llama3:latest",
        "message": user_msg,
        "conversation_id": conv,
    })
    data = r.json()
    conv = data["conversation_id"]   # reuse for next turn
    print(f"Bot: {data['response']}")

Supported File Types

CategoryExtensionsHow processed
Imagespng, jpg, jpeg, gif, webp, bmp, tiffSent as base64 to vision models
Documentspdf, docx, docText extracted, appended to prompt
Spreadsheetsxlsx, xls, csvData read row-by-row, appended to prompt
Code & textpy, js, ts, java, go, rs, c, cpp, html, css, json, yaml, sql, sh, …Content appended to prompt
Any text filetxt, md, log, conf, env, toml, …Content appended to prompt
Maximum file content sent to LLM: 80,000 characters (truncated if larger). Image files have no size limit beyond what the model supports.
